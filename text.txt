📝 Инструкция по активации модуля "Диагностика"
Когда нейросети будут доработаны, чтобы вернуть всё на место, выполните эти шаги:

Шаг 1: Возвращаем файлы на место
Зайдите в проводник вашего проекта и переименуйте файлы, убрав расширение .bak:

В папке lib/screens/: diagnosis_screen.dart.bak ➡️ diagnosis_screen.dart

В папке lib/services/: plant_model.dart.bak ➡️ plant_model.dart

Шаг 2: Восстанавливаем pubspec.yaml
Откройте файл pubspec.yaml.

Раскомментируйте зависимости в блоке dependencies:

yaml
  image_picker: ^1.2.4
  permission_handler: ^12.0.1
  onnxruntime_v2: ^1.23.2+2
  image: ^4.3.0
Раскомментируйте ассеты в самом низу, в секции flutter::

yaml
  assets:
    - assets/models/
    - assets/data/
Выполните в терминале: flutter pub get

Шаг 3: Восстанавливаем AndroidManifest.xml
Откройте android/app/src/main/AndroidManifest.xml и раскомментируйте разрешения перед тегом <application>:

xml
<!-- Разрешение на камеру -->
<uses-permission android:name="android.permission.CAMERA" />
<!-- Разрешения для галереи (Android 13+) -->
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
(Разрешение на READ_EXTERNAL_STORAGE у вас и так не закомментировано, его трогать не нужно).

Шаг 4: Обновляем main.dart
Откройте main.dart и внесите три изменения:

Раскомментируйте импорты в самом верху:

dart
import 'screens/diagnosis_screen.dart';
// import 'package:image_picker/image_picker.dart'; // можно оставить в комментариях, если он не используется прямо в main
// import 'package:permission_handler/permission_handler.dart';
В методе initState верните DiagnosisScreen на первое место (индекс 0):

dart
  _widgetOptions = <Widget>[
    const DiagnosisScreen(), // <-- РАСКОММЕНТИРОВАТЬ
    const CatalogScreen(),
    const CalculatorScreen(), 
    const SettingsScreen(),
  ];
В BottomNavigationBar верните первую вкладку:

dart
    items: <BottomNavigationBarItem>[
      const BottomNavigationBarItem( // <-- РАСКОММЕНТИРОВАТЬ
        icon: Icon(Icons.camera_alt),
        label: 'Диагностика',
      ),
      const BottomNavigationBarItem(
        icon: Icon(Icons.list_alt),
        label: 'Каталог',
      ),
      // ... остальные вкладки
Шаг 5: ⚠️ Критический фикс индекса в diagnosis_screen.dart
Поскольку вкладка «Диагностика» снова стала первой (индекс 0), а «Каталог» сместился на вторую позицию (индекс 1), нужно обновить логику переключения вкладки при нажатии на кнопку «Подобрать препарат».

Откройте lib/screens/diagnosis_screen.dart и найдите метод _applyFilters (ближе к концу файла).
Измените 0 на 1:

dart
  void _applyFilters(Set<String> species, Set<String> diseases) {
    FilterManager.instance.applyNewFilters(species, diseases);
    // ТЕПЕРЬ КАТАЛОГ СНОВА ВТОРАЯ ВКЛАДКА (ИНДЕКС 1)
    mainScreenTabNotifier.value = 1; 
  }
Шаг 6: Финальная сборка
Выполните команды очистки и сборки.
